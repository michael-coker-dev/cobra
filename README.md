# HTML & CSS Practice Projects

This repository contains two independent front-end recreation exercises:

- **Mixlr landing-page recreation** — `mixir.html`
- **SQI executive programme page recreation** — `sqi.html`

These pages were created for learning and layout-practice purposes. They are not official websites, are not affiliated with Mixlr or SQI, and should not be presented as commissioned client work or original brand designs.

## Run locally

Open either HTML file in a browser. The pages reference local image assets and some externally hosted fonts, images, and stylesheets, so the appearance may vary if those services change or are unavailable.

## Current limitations

- Several navigation and call-to-action links are placeholders.
- The pages are static demonstrations; forms and real service integrations are not implemented.
- The layouts need accessibility, responsive-design, and cross-browser testing before any reuse.

## Portfolio note

Use these as evidence of HTML/CSS practice only. For a professional portfolio, prioritize original projects with your own visual identity and working interactions.
